사용 가이드 팀 추가 → 직원 출근 → 맵에서 지시·보고

개념

  • 팀 = 레포 하나 = 출근 관리의 카드 하나. 「＋ 팀」으로 추가, 카드의 ✎ 로 수정.
  • 직원 = 그 팀의 Claude Code 세션(tmux 창). 카드의 「+」로 한 명씩 출근(id_1, id_2…), 줄 끝 「퇴근」으로 뺌. 출근하면 입구 문으로 걸어 들어와 앉습니다.
  • 방 = 팀이 앉는 곳. 팀 설정의 「방」에 이름을 적으면 생기고, 같은 이름끼리 한 방. 방 이름 옆은 그 레포의 브랜치.

순서

「＋ 팀」 → 폴더 목록에서 ⎇ 레포 클릭(작업실·이름·id 자동) → 방·권한 정하고 「저장하고 직원 1명 출근」. 팀을 다 만든 뒤엔 「전체 출근」 하나로 끝.

알아둘 것

  • 수정한 설정은 다음 출근부터. 떠 있는 직원 줄에 「설정 변경됨」이 뜨면 클릭해 재기동.
  • 팀 삭제는 한 번 클릭. 출근 중인 직원이 있으면 거부됩니다.
  • 저장 = company.yaml. 직접 고쳐도 되고, 팀 하나 저장하면 다시 읽음.
  • 지시는 대화창 터미널 탭에서 CLI 그대로. 요약 탭의 메모는 직원이 쉴 때 전달됩니다.
